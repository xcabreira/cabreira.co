# 🪵 Portfólio de Artesanato em Madeira

Um site simples para apresentar trabalhos em artesanato em madeira, como tábuas de corte, petisqueiras e peças personalizadas.

## ✨ Funcionalidades

- Exibição dos produtos em galeria
- Página responsiva
- Informações sobre cada peça
- Contato para orçamentos
- Design simples e intuitivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 📸 Produtos

- Tábuas de corte
- Petisqueiras
- Tábuas personalizadas
- Peças em madeira maciça

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/nome-do-repositorio.git
```

2. Abra o arquivo `index.html` no navegador.
